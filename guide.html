First start

  1. Just this device (local only): one tablet for both kids. Everything stays on the tablet. Parent mode is behind a PIN (the Parent button at the top).
  2. Parent Link: phones and tablets share the run through your private backend. Set up the backend first (backend SETUP.md).
  3. Kids are shown by initials only (one letter each).

Adding devices with Parent Link

  1. First parent phone: choose Parent Link, then "This is the first parent phone", and type the web app address, family key and parent secret from your setup sheet.
  2. Every other device: on a parent phone open Parent mode, Devices, Add a kid device (or parent device). On the new device choose Parent Link and scan the QR. Each code works once and expires in 10 minutes.
  3. A kid device opens straight to that kid's run and never shows parent tools.

Offline

After the first load the app works with no internet. Taps are saved on the device and go out when the internet is back. Parent phones check for news about once a minute.

PIN

The PIN only locks the screen. The server still decides what each device may do. Pick 4 to 8 digits.

Starting over on a device

Clear the site data for the app in the browser settings, then open it again and pair with a new code. The run history comes back from the server on a Parent Link device.
